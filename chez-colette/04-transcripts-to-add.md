# Which Transcripts to Put in the Claude Project

You asked for 7–10. Here are ten, ranked, with exactly what each one teaches. I read all twelve of
these in full, so the reasons below are what is actually in them, not guesses.

## How to add them (this part matters)

Do **not** paste raw transcripts. Prepend this header to each file, then upload it to the project's
knowledge:

```
=== STRUCTURAL REFERENCE ONLY — NOT CHEZ COLETTE ===
Channel: Bertha's Clean Home
Video: The Best Way to Clean Your Shower & Tub (The Mexican Way)
Runtime: 11:03 | Words: 2,007 | Views: 1.9M
Use this for: ARCHITECTURE (single-method spine), the cold-open physical command,
the absolution beat, the "who profits" essay, the fixed five-part close.
DO NOT reuse: any sentence, fact, example, or phrasing from this file.
=== END HEADER ===
```

Two reasons the header is not optional. First, without it Claude cannot tell a reference from a
Colette script, and will drift into Bertha's voice — no contractions at all, *mija*, Mexican
heritage framing. Second, the explicit "do not reuse" line, repeated in every file, is what stops
sentences leaking from the references into your output. The project instructions enforce this too,
but knowledge files carry a lot of weight and this is cheap insurance.

## Do not add

- More than about twelve files. Past that you are diluting, not enriching, and the project starts
  averaging across voices instead of learning a structure.
- Transcripts from Ray Dutton's Garage, Earl Jackson BBQ, or Otis Granger. They are the same
  template as Bertha and Elias, so they add nothing new and they add three more voices to drift
  toward.
- Any Chez Colette script until you have one you are genuinely happy with. Then add it, headed
  `=== CHEZ COLETTE — APPROVED SCRIPT — MATCH THIS VOICE ===`. One approved script of your own is
  worth more than five references, because it is the only file in the project that is actually in
  her voice. Replace it as your voice improves.
