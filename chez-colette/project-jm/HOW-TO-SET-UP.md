# The second script project — The Japanese Method structure

A second Claude project that writes Colette's scripts in **The Japanese Method's**
structure instead of Bertha's and Elias's. Same Colette, same book, same facts —
different shape.

Your existing project stays exactly as it is. You now have two, and you can test
which structure keeps viewers watching longer.

## Writing a script

New chat inside the project. Paste these four things:

```
TITLE:       the exact title of the video
TRANSCRIPT:  the Japanese Method video you're adapting
LENGTH:      e.g. "18 minutes"
USED SO FAR: paste the whole of USED-SO-FAR.txt
```

It replies with the script and nothing else.

**Length guide** (185 words a minute):

| Runtime | Words | Shape |
|---|---|---|
| 10–12 min | 1,850–2,220 | problem-solver only, 4–5 problems |
| 13–16 min | 2,405–2,960 | 7 items, or problem-solver |
| **17–20 min** | **3,145–3,700** | **9–11 items — their own sweet spot** |
| 21–24 min | 3,885–4,440 | 11–15 items |

**After a script is final,** tell me "004 is final" and I'll add its entries to the
ledger — or ask the project itself for "the ledger entries for the script you just
wrote" and paste them in yourself.

## Two warnings

**Their videos are full of things Colette can't say.** Health scares, invented
statistics, named brands being accused, "designed to fail", a Japanese word in every
item. The instructions ban every one of these by name, because a model that reads
them twenty times will copy them. If a script slips one through, it failed the
instructions — tell the project which line and ask for a rewrite.

**Don't copy their titles word for word.** Video 003's title was a near-copy of their
biggest video, and YouTube showed it right next to theirs — 91% of your impressions
came from Suggested. Next to the original, a copy looks like the imitation. Change
the promise, not just the nationality, and keep the whole promise inside the first 60
characters, because that's all a sidebar card shows.

## How you'll know which structure works

Not from CTR — that's title and thumbnail, not script. Look at **Audience retention**
once each video has a few hundred views:

- **Retention at 30 seconds and at 1 minute.** This is where the short hook should
  win. If it doesn't, the structure isn't helping.
- **Average percentage viewed.**

Make two or three videos in each structure, on similar topics, before deciding.
One video each proves nothing.
