A second Claude project that writes Colette's scripts in **The Japanese Method's**
structure. Same book, same facts — but the video is about the viewer's home, not
about Colette, and nothing is ever said the same way twice.

## Setting it up

**1. Create the project** in Claude — e.g. *Chez Colette — List Method*.
If you already made it, just replace its instructions (step 2) and add the new
knowledge files (step 3).

**2. Instructions box:** paste the whole of `PROJECT-INSTRUCTIONS-JM.txt`,
replacing anything already there.

**3. Knowledge** — upload:

- `COLETTE-REFERENCE.txt` — the same file as your first project.
- The 10 transcripts from the zip (JM-01, 02, 03, 05, 06, 07, 10, 12, 13, 17).
- **`SPENT-002-french-secrets.txt` and `SPENT-003-french-organisation-rules.txt`** — new.

## The SPENT files — this is how it stops repeating itself

A new chat remembers nothing. The only way the project can avoid your old sentences
is if it can **read** them. So every script you publish goes into its Knowledge as a
SPENT file, and the instructions tell it that nothing in a SPENT file may appear again.

**After every video you publish:**

1. Copy the exact script you recorded into a plain text file.
2. Name it `SPENT-` + the video number + a short title, e.g.
   `SPENT-004-hallway-rules.txt`.
3. Upload it to this project's Knowledge.

That's it. No ledger to paste, nothing extra in the chat.

> **Check 003:** the SPENT-003 file I made holds the **revised** version of script
> 003. If you recorded the original draft instead, upload that text instead — the
> file has to match what's actually published.

## Writing a script

New chat inside the project. Paste three things:

```
TITLE:      the exact title of the video
TRANSCRIPT: the Japanese Method video you're adapting
LENGTH:     e.g. "18 minutes"
```

It replies with the script and nothing else — no note before or after it.

| Runtime | Words | Shape |
|---|---|---|
| 10–12 min | 1,850–2,220 | problem-solver, 4–5 problems |
| 13–16 min | 2,405–2,960 | 7 items, or problem-solver |
| **17–20 min** | **3,145–3,700** | **9–11 items — their sweet spot** |
| 21–24 min | 3,885–4,440 | 11–15 items |

## Two warnings

**Their videos are full of things Colette can't say** — health scares, made-up
statistics, named brands being accused. The instructions ban each one by name.

**Don't copy their titles word for word.** Video 003 did, and YouTube showed it right
next to their original, where yours looks like the copy. Change the promise, not just
the nationality, and keep it inside the first 60 characters.

## How you'll know which structure works

Not CTR — that's title and thumbnail. Look at **Audience retention** at 30 seconds
and 1 minute, and **average percentage viewed**. Make two or three videos in each
structure before deciding.
